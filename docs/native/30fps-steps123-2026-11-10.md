## Step 1: CPU clock toggle (ffns_cpu_mhz; menu System > CPU clock: 1020 stock / 1224 / 1428; default 1020)
- The game sets the clock itself through clkrst (PcvModuleId_CpuBus), no sysmodule (sdk/src/ui/switch_apm.cpp,
  tools/build/cpu_oc_patch.py). Stock clock put back at exit (rex_app.cpp, windowed_app_main_switch.cpp).
- Horizon puts 1020 back: a session per call (p10a) -> no gain; once a second (p10b) -> 1428 gave only ~+10 %
  (1020: 19.79 / 19.52, 1428: 22.24 / 20.94 fps). Final (p10c, p11): a pin thread on core 3 (priority 0x2C), one
  persistent clkrst session, reads every 20 ms: the log shows 2 re-sets in the first 10 s, then 0 per 10 s (the clock holds).
- Field S1b at 1428 (non-PGO p10c, windows 4-10): ~25.5 fps (pg01 / pg04) vs ~19.7 at 1020: about +30 %.
